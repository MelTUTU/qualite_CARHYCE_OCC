# **Mise en qualité des données CARHYCE**

Ce dépôt contient les fonctions et scripts Rmd utilisés par l'OFB Normandie pour la mise en qualité 
des données CARHYCE.


Il permet d'aboutir, à partir des données brutes, à la création de fiches par stations générées au format html. 
Ces fiches permettent ensuite de mettre en évidence les éventuelles erreurs de saisie, données 
aberrantes et points de vigilance.

La procédure d'export et de stockage des données CARHYCE est présentée dans le fichier "001_Preparation_donnees.html".
